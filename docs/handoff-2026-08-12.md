## Enabling PostgreSQL in a deploy run

1. Add `TF_VAR_postgres_admin_password` to the repository secrets (Settings → Secrets → Actions).
2. Pass `-var="deploy_postgres=true"` to the `terraform apply` step, **or** set the workflow environment variable `TF_VAR_deploy_postgres=true`.
3. On first deploy the Flexible Server will be provisioned and the KV secret written. The API container app will be redeployed with the `ConnectionStrings__ClinicFlowDb` env var populated.
4. After infra apply, run EF migrations: `dotnet ef database update --project src/ClinicFlowAi.Infrastructure.Postgres --startup-project src/ClinicFlowAi.Api`.
